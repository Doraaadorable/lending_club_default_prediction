PSI below 0.10 is read as stable, 0.10-0.25 as a moderate shift, above 0.25 as a large shift. PSI ignores missing values, so a change of 5% or more in the share missing is also read as moderate, 20% or more as large; a PSI that cannot be computed (for example, every current value missing) is read as invalid and treated as a failure.

No feature reaches the moderate threshold.

Every p-value is far below 0.05, which here reflects the sample sizes: the tests detect differences that are real but small, so drift is read from PSI.
