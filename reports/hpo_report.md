## 1. TPE against random sampling for gradient boosting (40 trials each, 5-fold CV, the same median pruner)

Both studies use the same search space, objective, folds and pruner in the same run; only the sampler differs. TPE's first 10 trials are random start-up trials; with the same seed they are the same 10 configurations as the random sampler's, so the samplers only differ from trial 11. A trial is pruned only before its last fold. Fold fits count the CV folds actually trained, since pruned trials stop early. One seed per sampler: the comparison shows behaviour on this problem, not a general ranking. The median of completed trials describes each run; because pruning decides which trials complete, it does not isolate sampler quality.
